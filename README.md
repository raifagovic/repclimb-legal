# RepClimb Legal Site

These files are ready for GitHub Pages.

## Publish

1. On GitHub, create a new public repository named `repclimb-legal`.
2. Upload the contents of this `RepClimbLegal` folder to the repository root.
3. Open `Settings > Pages` in the new repository.
4. Under `Build and deployment`, select `Deploy from a branch`.
5. Select the `main` branch and `/ (root)`, then save.

The pages will be available at:

- `https://raifagovic.github.io/repclimb-legal/privacy/`
- `https://raifagovic.github.io/repclimb-legal/support/`

Use the privacy URL in App Store Connect under `App Privacy > Privacy Policy`.
